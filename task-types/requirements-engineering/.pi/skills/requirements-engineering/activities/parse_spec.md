## 这类任务在逆向解析阶段

**这一步读的是什么。** 材料目录里放在「既有规格说明」上传位的那一份，是用户认定对目标系统有效力的旧版规格说明，这一步只读它。别的材料是补充证据，这一步不读、不搜，也不拿来对照，那是下一步核读材料的事；用 grep 时 path 写那份既有规格说明本身，不写材料目录（N-4）。

**第零步：先判断它是不是一份规格说明。** 动笔之前先读分段清单与前两章，按三条判据判断这份文件是不是在规定目标系统应当做什么：一是有按条列出的需求语句或用例（有编号、有表格，或者用「应」「须」的句式）；二是有系统范围或总体描述的一章；三是叙述的对象是待建或在用的系统，而不是项目本身（预算、进度、组织属于项目）。至少满足两条才往下做。不满足时停下，发一张请选择卡片：成文的话里写明哪几条不满足，每条各举一处原文为证；两个候选是「改走需求分析，把这份文件当普通材料核读」与「继续解析」。用户选继续就照常往下做。这是这一步唯一一次问用户（A-3、A-4）。三条判据逐条写满足或不满足、各引一处原文。满足时不发回复，把这段判断原样写进第一次保存的「理解」里再往下做；不满足时才发上面说的请选择卡片（A-3）。

**保留作者的结构。** 按原文章节的先后逐节处理，不按平台的章重排。章节名、术语、角色名一律沿用原文；平台对同一件事另有叫法的，在页的「别名」一栏记下原文的叫法。页的标题逐字取原文的节名，去掉编号即可，不另起标题，不加「的」「说明」之类的字；原文节名重复时在标题后加原文的节号区分（M-1）。

**每一节去哪里。** 照下表逐节映射。去向是某一章的，立业务说明的页，标签按任务类型说明「业务说明的每一页怎样填」选；去向是条目的，存进对应的集合（M-2、N-8）。

| 原文章节 | 去向 |
|---|---|
| 引言、目的、范围、总体描述 | 概述与范围章 |
| 业务目标 | 业务目标章 |
| 用户特征、角色、权限 | 角色章 |
| 业务流程、场景 | 业务流程章 |
| 术语表 | 概念页 |
| 假设与依赖 | 假设页 |
| 数据字典、对象说明 | 业务对象章 |
| 功能需求、用例、功能点表 | 功能用例条目 |
| 性能、可靠性、安全性、可用性 | 非功能需求条目 |
| 设计约束、技术约束、法规约束 | 约束条目 |
| 修订历史、参考资料、文档约定、审批页 | 不提取，在收尾汇报里写明 |
| 图 | 本期不处理；有文字说明的按文字处理 |

修订历史、参考资料、文档约定、审批页不提取，图不处理，这些都在收尾汇报里逐项写明。

**按块推进。** 材料带分段清单的（Word、PDF）先读清单再按块读；没有分段清单的（md）按原文的章读，一次读一章。每处理完一块就保存这一块的产出，然后读下一块。不把整份文档读进来再统一产出。一次保存只做一个操作：立一页、改一页、存一条条目或记一条问题条目各算一次，看到保存成功再做下一个（M-6、M-7）。

**不做的事。**
- 不替作者补内容：不补缺的字段，不补推断出来的前置条件，不补「合理的」非功能指标（N-1）。
- 不改写句子，不统一术语，不纠正原文的错别字与病句；要指出就记问题条目，原文照旧（N-2）。
- 不合并相似的条目，不拆分复合的条目（N-3）。
- 不读补充证据，不与证据对照（N-4）。
- 不评价原文写得好不好、合不合规，不记「写法不合规」一类的问题；那是评审确认一步的事（N-5）。
- 除第零步之外不向用户提问（N-6）。
- 不立映射表页、工作记录页、术语对照页，不把解析过程写进业务说明（N-7）。

**收尾。** 收尾之前用查找知识库工具查一次，查的话写「客户的需求写作规范或需求编写规范」。查到客户规范就在汇报里加一句「写法判据参照《规范名》」，并记一条种类为待澄清的问题条目，事项写「评审时按《规范名》核对写法」，关联条目留空。没查到或任务没有选知识库就什么也不加，汇报里不提（M-9）。

原文逐节处理完、再从头核对一遍每一节都有去处之后，在回复的成文的话里汇报三项：原文每一节的去向，或者不提取的理由；「原文未给」的问题清单；立了几页、各类条目各几条。然后发提议进入下一步核读材料的卡片，成文的话里说明下一步要对照哪几份补充证据（M-8）。

## 字段怎样对位

- 原文的一列落到条目的一个字段，句子逐字照录，指示词也不换：原文写「本」「该」「此」就照抄「本」「该」「此」，不改成「这份」「这个」；原文的标点照抄；不改写、不润色、不翻译术语。原文有而平台没有的列不另存，它留在来源引用的原文里（M-4）。
- 平台要求必填而原文没有给出的字段，写「原文未给」四个字，并在同一批里记一条种类为缺失的问题条目，「关联条目」写那一条条目；一条条目缺几个字段只记一条问题，在「事项」里把缺的字段列齐，例如「UC-003 原文未给前置条件、后置条件」。只写了「原文未给」而没有配对的问题条目，保存会被拒（M-5）。
- 每页每条的来源写「文档原文」，摘录逐字抄自既有规格说明，出处指向原文的那一节；不引补充证据（M-3）。
