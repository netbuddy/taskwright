# fixtures 目录

这里放建新工作区用的模板。一个模板是一个目录，里面是工作区的起始文件。

任务服务建任务时（网页上的「新建任务」，或接口 `POST /api/v1/tasks`）按任务类型把这里对应的目录整个复制成新的任务目录，
再写任务记录（`backend/src/workspace.ts`）。

模板里**不放** `AGENTS.md`：pi 会把它当作上下文文件追加到系统提示后面，容易把模型带偏。

| 模板 | 它是什么任务 |
|---|---|
| `srs-authoring/` | 软件需求规格说明编制。代码仓里只有这一份它的起始文件副本：任务服务建任务（`backend/src/workspace.ts`）与测试都用它。正本在设计文档那边，改 skill、规矩文档或任务定义时两边一起改；这里不放试验材料，`inputs/` 由建工作区时建出。 |
| `term-clarification/` | 术语澄清。这是按条目记版本之前的旧模板，任务定义是旧的形状（按槽位记字段），「创建任务」工具不认它，会拒绝并逐条说明哪里不对。留着只作对照。 |
