# fixtures 目录

这里放建新工作区用的模板。一个模板是一个目录，里面是工作区的起始文件。

`python -m taskwright_server.new_workspace <新工作区目录> --template <模板名>` 会把模板整个复制到新工作区，
不建库。更常用的是 `--from <起始文件目录>`，直接从代码仓之外的一个起始文件目录复制。

模板里**不放** `AGENTS.md`：pi 会把它当作上下文文件追加到系统提示后面，容易把模型带偏。

| 模板 | 它是什么任务 |
|---|---|
| `srs-authoring/` | 软件需求规格说明编制。代码仓里只有这一份它的起始文件副本：创建任务（`create_task.py`）、`new_workspace --template srs-authoring` 与集成测试都用它。正本在设计文档那边，改 skill、规矩文档或任务定义时两边一起改；这里不放试验材料，`inputs/` 由建工作区时建出。 |
| `term-clarification/` | 术语澄清。这是按条目记版本之前的旧模板，任务定义是旧的形状（按槽位记字段），「创建任务」工具不认它，会拒绝并逐条说明哪里不对。留着只作对照。 |
