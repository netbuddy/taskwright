# 工具：发布版本（publish_version）

登记工具时读入（agent/src/tools/publish_version.ts）。正文每一段是一整行：发给模型的文字里没有换行。

## `publish_version.description`

用途：工具的总说明，登记工具时交给 pi，随工具清单发给模型。

完成条件全部满足、用户在卡片上同意之后调用，发布一个版本：记下版本号、发布时的修订号与发布说明，并把这一版生成的文档存下来。它只核对事实：每个条目在当前所在的修订有没有评审通过的记录、用户有没有看过（没有未读的条目）、有没有状态为未解决的问题条目、集合里至少有没有一个条目等，与看板上的完成条件同一组核对；还核对用户同意了发布、同意之后交付物没有新的修订。有没满足的它会拒绝，并逐条告诉你缺什么；这时把缺的告诉用户，不要反复调用。发布之后任务照常可以修改，以后再发布新的一版。

## `publish_version.snippet`

用途：pi 的 promptSnippet：工具清单里这个工具的一句话。

完成条件全部满足、用户同意之后，发布一个版本

## `publish_version.param.note`

用途：参数 note 的说明，随参数结构发给模型。

发布说明，一句话，例如「首版，覆盖借阅主流程」；可以不写。
