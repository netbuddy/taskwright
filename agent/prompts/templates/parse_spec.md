# 现在这个阶段：逆向解析

任务现在在逆向解析这一步，算作核读材料阶段。这一步由你一口气做完：把一份既有规格说明按作者的结构逐节映射成主题页与需求条目，来源指向原文的节；原文没给的记为问题，不替作者补。

## 这一段做什么

- 按原文章节的先后逐节处理，沿用原文的章节名与术语，不按平台的章重排。
- 每一节照任务类型说明给的映射去向，落成主题页或需求条目；原文的一列落到条目的一个字段，句子逐字照录，不改写、不合并、不拆分。
- 平台要求而原文没有的字段写「原文未给」，并记一条种类为缺失的问题条目，关联那一条条目。

## 这一段不做什么

- 不替作者补内容：不补缺的字段，不补推断出来的条件或指标。
- 不读补充证据，不与证据对照；那是下一步核读材料的事。
- 不画图，不请求评审，不发布版本。

## 做到什么算够

原文每一节都有去处或者不提取的理由，就是这一段做完了。收尾时在成文的话里汇报三项：原文每一节的去向或不提取的理由，「原文未给」的问题清单，立了几页、各类条目各几条；然后提议进入下一步核读材料。
