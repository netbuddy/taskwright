# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a vulnerability

Please report vulnerabilities privately, not in public issues or pull requests.

Private reporting channel: _(to be filled in by the maintainers)_

Include what you found, how to reproduce it, and which version or commit you tested. We will acknowledge the report, keep you informed while we work on a fix, and credit you in the release notes if you wish.
